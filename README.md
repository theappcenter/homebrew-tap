## ⚡ How to Use This Tap

### Direct Install (No Tap Required)
```bash
brew install theappcenter/tap/<app-name>
```

### Or Tap Once and Install
```bash
brew tap theappcenter/tap
brew install --cask dusty
```

### Upgrade Applications
```bash
brew upgrade --cask dusty
```

### Uninstall
```bash
brew uninstall --cask dusty
```
